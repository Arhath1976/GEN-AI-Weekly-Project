What's Running

  • Python 3.11.0 virtual environment
  • FastAPI backend server
  • ServerAgent message endpoint
  • Browser-based ClientAgent
  • JavaScript fetch request system

How It Works

  1. User types a message in the app.
  2. ClientAgent prepares a JSON message.
  3. Message is sent to /message.
  4. ServerAgent receives and processes it.
  5. ServerAgent sends a JSON reply.
  6. The app displays the reply.
